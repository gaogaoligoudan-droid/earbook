# EarBook 流畅度与缓存体系 · 产品评估（R3）

> 2026-10-07 · 码龙 · 依据 REQUIREMENTS.md 需求骨架（R1/R5-R11 全部已拍板项）
> 结论先行：**方案骨架无需再选——用户已定（双引擎+章级缓存+追上弹窗+AAC+无上限）；
> 本文档给出量化数字、两项待批参数、实施与风险清单。**

---

## 一、问题根因（实测数据）

| 指标 | 数值 | 来源 |
|---|---|---|
| Mi Note 3 合成速度 | RTF≈10-15（1 分钟音频合成 10-15 分钟） | 10-07 真机轨事件间隔 |
| 句均合成耗时 | 20-30 秒（2-4 秒音频） | 同上 |
| CI 模拟器（x86） | RTF 2.29 | 10-07 CI E2E |
| 句间停顿感受 | 一顿一顿（用户 10-07 原话） | — |

**根因**：现场合成（边渲边播）在 RTF>1 设备上物理不可连续。用户已拍板的解法
（R6 双引擎：神经=先缓存后播）正确且是唯一路线。本机现场合成路径保留为
「未缓存章节的降级」不存在——按 R9 拍板，追上缓存即弹窗二选一，永不现场合成播放。

## 二、现有架构盘点（为什么 M3-2 从没跑起来）

- ChapterAudioCache（章 WAV + 句偏移落盘）✅ 已实现且 speak() 有命中路径
- PrerenderWorker（WorkManager）✅ 已实现，但约束 = charging+idle → **测试期间从未触发**
  （屏幕常亮 ≠ idle）；且只排 chapterIndex+1 起——**当前章永远不渲**，设计即缺口
- 缓存上限滑块+LRU：按 R11 拍板**移除**
- 系统多 lexicon 单位歧义、AudioTrack 生命周期等播放 bug：10-07 已修待提交

**结论**：骨架大半已在，缺的是「当前章优先 + 起播门槛 + 进度 UI + 授权向导 +
AAC 化 + 管理页」——即 R6/R8/R9/R11 的 UX 与调度层，非推倒重来。

## 三、设备分档与体验预期（核心数字）

| 设备档 | RTF 估计 | 3 章起播等待¹ | 边听边缓存 | 长书体验预期 |
|---|---|---|---|---|
| Mi Note 3（2017 SD660）| ~10 | **1.5-3 小时** | 永远追不上 | 弹窗频繁；神经模式适合短书/插电批量渲 |
| 中端 2023（SD7 系）| ~1.5-3 | 15-40 分钟 | 勉强追上（0.8x 播放时可追）| 基本可用，偶发弹窗 |
| 旗舰 2024+ | <1 | 5-15 分钟 | 轻松领先 | 完整体验，弹窗基本不出现 |
¹ 网文一章按 4 分钟音频估

**产品策略**：不按机型锁功能（无法可靠探测档位），**按体验诚实分级**——向导里
给出本机实测的预估等待时长（首章合成一次即可标定 RTF），用户知情选择。
Mi Note 3 这类机型上系统语音模式是主力，神经模式定位为「插电预约渲染」。

## 四、待批参数（仅两项，其余全按已拍板项执行）

1. **AAC 码率**：建议 **32kbps mono**（语音够用，≈ 4MB/小时音频；64k=8MB/小时更
   保险）。→ 请拍板 32 还是 64
2. **「插电预约渲染」**：慢机型向导里提供「插电时自动缓存全书」选项
   （复用现有 charging 约束 WorkManager）→ 请拍板要不要

其余实施参数（章渲染顺序、通知栏样式、预估公式系数）属工程细节，按最佳实践定，
不占用拍板带宽。

## 五、实施方案（R6+R8+R9+R11 一体，M1-M4 里程碑）

- **M1 数据层**：缓存改 AAC（MediaCodec 编码，WAV 落盘→AAC 落盘一章原子替换）；
  章级资产登记（优化标记/缓存标记/音色/尺寸）；存储预估公式；移除滑块+LRU
- **M2 调度层**：前台渲染服务（通知栏进度=R8a）+「当前章优先→后续章队列」；
  R8b 授权映射（电池=前台服务 / 仅插电=WorkManager）；追上检测→暂停+弹窗二选一
- **M3 UX 层**：首次向导（模式+书级音色+授权+预估，鼓励式）；长按「书籍管理」页
  （状态徽标/资产删除/音色切换/模式切换）；存储管理页（每书尺寸+总占用）
- **M4 变速+导出（R5/R10）**：AudioTrack 保音高变速 0.8-2.0x；AAC→M4A 容器
  导出（零转码）+ SAF/分享
- R7（AI 优化层）挂 M1 管线：章缓存前 hook DeepSeek flash，按章幂等，失败即原文

## 六、风险清单

| 风险 | 等级 | 对策 |
|---|---|---|
| 各 OEM 激进电池管理杀后台（渲染中断，通用风险非 MIUI 专属）| 高 | 前台服务+通知；断点续渲（章级原子性天然支持）；通用后台权限指引文档化（不做 OEM 私有逻辑，用户 2026-10-07 拍板） |
| MediaCodec AAC 兼容（Android 9）| 中 | 编码失败降级存 WAV（体积大但可用）；真机早期验证 |
| 追上弹窗在慢机频繁打扰 | 中 | 弹窗记住选择（本次播放会话内不再问）|
| AAC 音质劣化 | 低 | 32→64k 可调；A/B 听感验证后定 |
| 存储吃满（无上限）| 低 | 已有预估预警+低空间提醒双保险（用户拍板方案）|
